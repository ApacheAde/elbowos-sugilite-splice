# Sugilite Splice

Full-colour Python 3 neon helix colour-fuse arcade for ElbowOS.

Hex gems fall in twin lanes through a violet helix. When a matching pair sits in the splice gate, lock them. Orchid, lime, cyan, gold, and coral bases fuse into a bloom. A mismatch cracks the streak.

Not a commercial emulator and not a ROM player.

## Play

```bash
pip install -r requirements.txt
python3 sugilite_splice.py --play
```

Space, click, or Up splices. R restarts.

## Record a 9:16 reel

```bash
python3 sugilite_splice.py --record
```

Headless autoplay writes a 1080x1920, 15s, 30fps H.264 MP4. Override the path with `ELBOWOS_MP4`.
